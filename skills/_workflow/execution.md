# Execution and delegation

Inputs: approved orchestration, full, or fast plan, or autonomous one-shot plan, workspace, and verification commands.

1. Maintain [the taskboard](templates/taskboard.md) at `<main-repo>/.agent-docs/taskboard/<feature>.md` for orchestration and full tracks, [the fast-track record](templates/fast-track.md) for fast, or the progress section of [the one-shot run document](templates/run.md). Update the active file in place so unfinished work is easy to find. Keep small completed items as compact checkboxes; when a taskboard grows large, move detailed completed work to `.agent-docs/archive/` and retain a short summary in the active file.
2. Implement dependency-ready tasks according to track requirements:
   - **Orchestration track execution.** The frontier orchestrator Gemini 4 Argon coordinates end-to-end alignment and architectural cohesion while actively minimizing its own token usage. Rather than generating implementation code directly or ballooning conversation context, the orchestrator slices features vertically by grouping business logic, tests, and UI together into verifiable end-to-end deliverables rather than horizontal architectural layers, and dispatches implementation slices to smaller subagents with `Model: "flash"` or `Model: "flash_lite"` via `invoke_subagent`. If a slice fails verification after two attempts or encounters deep architectural obstacles, escalate the implementation subagent to `Model: "pro"`.
   - **Full-track execution.** Full-track mandates subagent delegation for task implementation, dispatching scoped subagents for each task while the orchestrator coordinates dependencies, reviews evidence, and updates the taskboard.
   - **Fast-track execution.** Fast-track executes linearly in the current session without implementation subagents.
   - **One-shot execution.** One-shot delegates independent tasks when the benefit justifies coordination, leveraging boost capabilities autonomously.
   Give simultaneous writers disjoint file scopes and isolated resources.
3. For delegated implementation, provide [a scoped implementer brief](templates/implementer-brief.md), requirements, workspace path, and relevant commands via `invoke_subagent`. Select subagent models by capability tier according to the active adapter, assigning `flash` or `flash_lite` for vertical implementation slices in orchestration, standard coding tier in full-track, and escalating to `pro` for high-reasoning fixes. Antigravity orchestrators rely on automatic reactive wakeups upon subagent completion, background task events, or scheduled timers, and must never poll or loop on task status. For read-only code exploration in any track, use the scoped assignment and report requirements in [discovery](discovery.md#code-exploration-and-delegation). Do not create user-visible sidebar chats as an implementation mechanism unless requested.
4. Follow [test integrity](testing.md). Inspect returned changes and recorded red and green command evidence rather than accepting unsupported claims. Reproduce relevant checks when evidence is missing, suspect, or affected by combining parallel tasks.
5. Resolve findings with concrete corrections, capping failed task implementation attempts at 3 and review-fix cycles at 3 rounds. Use [independent review](review.md) for the completed candidate and optionally earlier for high-risk tasks. Record review results before marking requirements done.

When a task fails or an approach is abandoned, update the active document in place with the current approach and a short explanation of what was tried and why it failed, moving lengthy logs or superseded plans to `.agent-docs/archive/`. If the 3-attempt or 3-round cap is reached during an in-place run, restore modified candidate files back to their pre-task state while preserving pre-existing user changes and keeping the failure record in `.agent-docs/`. Apply the track's escalation policy from [core](core.md).

Completion: required tasks are implemented and reviewed, or exhausted attempts are rolled back in place and documented with remaining blockers accurately recorded.
