# Claude Code adapter

Use the active session's tools and supported subagent configuration. Follow [repository-local worktree placement](../workspace.md). Use native worktree support only when it accepts `<main-repo>/.worktrees/`; otherwise use Git directly. Do not use a Claude-owned directory as a fallback. Give independent reviewers a fresh context using [the reviewer brief](../templates/reviewer-brief.md).

This branch's installer targets Antigravity only. In a separately configured Claude Code environment, permit automatic orchestration-track, full-track, and fast-track selection by scope. Keep one-shot explicit-only through supported runner controls. Do not assume the installer creates Claude-specific metadata.

Use native subagents for read-only code exploration under [discovery](../discovery.md#code-exploration-and-delegation), including in fast-track. The orchestrator may read documentation directly. Select supported subagent models and reasoning settings by universal capability tier: lightweight scanning for bounded retrieval, standard coding for scoped investigations and track-permitted implementation, and high-reasoning for demanding investigations, architectural reasoning, independent review, and escalated fixes. Map tiers to the active session's capabilities rather than fixed provider model IDs, using discovery's fallback when delegation or model selection is unavailable. Use available browser inspection tools for UI verification, and honor the harness's sandbox and permission controls.
